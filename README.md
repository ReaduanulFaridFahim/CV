An executive, responsive web-based digital resume and career portfolio engineered in clean, semantic HTML5, modern CSS3 custom properties, and responsive grid layouts.

---

## 🚀 Key Highlights

- **Live Deployment**: Hosted on GitHub Pages at [readuanulfaridfahim.github.io/CV/](https://readuanulfaridfahim.github.io/CV/).
- **Mobile-Responsive Glassmorphism**: Tailored for desktop, tablet, and mobile displays with fluid grid positioning.
- **Dedicated Print Stylesheet (`@media print`)**: Automatically formats into a crisp, high-contrast monochrome layout when printed or saved as a PDF via the browser.
- **One-Click Actions**:
  - `Print / Save PDF`: Triggers browser native PDF export dialog.
  - `Copy Contact Info`: One-click clipboard copy with animated toast notification.
  - Quick outbound links to live deployments and portfolio.

---

## 🛠️ Section Architecture

1. **Executive Bio & Identity**: Candidate headline, avatar, and real-time availability status.
2. **Contact Matrix**: Phone, email, LinkedIn, portfolio, and location coordinates.
3. **Academic Credentials**: B.Sc. in Computer Science & Engineering from North South University (NSU).
4. **Technical Arsenal**: Grouped into AI/ML, SQA Automation, Autonomous Systems/Databases, and Tooling.
5. **Solutions Architecture & Experience**: Detailed project delivery across autonomous AI workflows, mobile automation, and computer vision research.
6. **Flagship Systems**: Direct repository and live demo links to top engineered applications.

---

## 💻 Tech Stack

- **Markup**: Semantic HTML5 with accessibility metadata
- **Styling**: Modern Vanilla CSS3 (Custom properties, CSS Grid & Flexbox, Backdrop Filter blur)
- **Zero Heavy Dependencies**: 100% lightweight, ultra-fast load time, zero framework overhead
- **Typography**: Google Fonts (*Inter*)
